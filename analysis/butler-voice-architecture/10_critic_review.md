# Критическая проверка отчёта

Самопроверка источников, формулировок и ссылок. Это проверка отчёта; она не заменяет независимую проверку кода или реальную приёмку голоса.

## Проверки и внесённые уточнения

| Проверка | Найденная проблема черновика / риск ошибки | Итог |
| --- | --- | --- |
| Installed против source | Нельзя показывать 0.6.4 исправление как уже работающее | В каждом основном документе отдельно указаны installed 0.6.3/core 0.15.0 и source candidate 0.6.4; подтверждены RPC и manifest |
| Причина тишины | Traceback доказывает смерть потока в конкретном сбое, не каждый предыдущий miss и не отсутствие более позднего рестарта | Ограничение явно включено; thread liveness не выдумана из общего status |
| Реестр таймеров | 180 s Session.touch меняет started_at, а не удаляет всю историю | Формулировка исправлена/уточнена; recency, authorization, deadline и retention разделены |
| Изоляция inference | В черновой схеме call conclusions были объединены со всем фоном 11434 | Проверен Calls.conclude: он использует voice.model/11435. Схема разделена; RA-14 указывает предел доказанной изоляции |
| Reproducibility | Исторический hotfix script не соответствует текущим 0.6.4 командам | Убрана ссылка как на точную процедуру; оставлены зафиксированные commands/cwd/exit и явная команда профильного запуска |
| Пути ссылок | Относительный путь к installed site-packages мог разрешаться неверно | Заменён абсолютным путём; все локальные Markdown targets проверены |
| Новые правила против старых criteria | Недостаточно дописать короткий ответ на вопрос, если старое правило всё ещё безусловно отвергает короткие фрагменты | Через MarkView уточнены исключения pending-question/confirmation в REQ-056/057 без снятия action/identity guards |
| Security claims | Очередь deferred без origin epoch — риск; доказательства фактической утечки нет | Сохранено различие факт структуры / риск последствий; SEC-1 не выдаётся за утечку |
| Audio completion | `dataPlayedBack` не подтверждает слышимость и полноту произнесённых слов | Разделены prepared/generated/buffer delivered/acoustically verified |
| Framework claim | Наличие Pipecat worker не значит, что вся orchestration — Pipecat pipeline | Это прямо указано в архитектуре и RA-12 |
| ASR accuracy | Непустой текст/низкий logprob не дают полного знаменателя качества; отсутствие числовых scores не равно подтверждённой уверенности | Описана ветка confident() без scores, нет выдуманного WER/80% |
| Готовность | 64 profile tests 0.6.4 нельзя назвать полным новым suite; build не доказывает UX | Coverage lineage и открытые acceptance показаны явно |

Основания: [runtime evidence](runtime_evidence.json), [код и реестр сроков](02_architecture_analysis.md), [расхождения](06_contradictions.md), [проверка ссылок](document-validation.json).

## Ограничения покрытия

- Анализ охватывает всю feature-папку и фактическую цепочку голоса; он не является построчным аудитом всех функций всего проекта.
- Отсутствующее/истёкшее аудио не восстановлено; не создавался долговременный акустический датасет.
- Gateway/provider internals не подменяются догадкой. Подтверждена буферизация нашего клиента, серверный typed streaming/cancellation contract остаётся предметом проверки.
- Предлагаемый координатор и новые протоколы ещё не реализованы и не приняты как отдельное окончательное техническое решение владельца.
- Диаграммы проверены по стрелкам/кодовым путям и синтаксической структуре текста; отдельный browser render не выполнялся. Проверка в MarkView browser не входит в цель.

## Результат

Отчёт пригоден для обсуждения и дальнейшей реализации: основные выводы имеют прямые ссылки, предположения отмечены, каждому риску/пробелу предложена проверяемая мера. Это не закрывает обнаруженные дефекты и исходную цель. [Итог](09_final_dossier.md).
