## Assumptions

**A-3. Предлагаемый единый координатор упростит гонки без замены всех моделей.** Основание: установленные дефекты находятся в нескольких точках оркестрации и подтверждены кодом, [RA-01–10](06_contradictions.md). Уверенность Medium: архитектурная логика сильная, но результат ещё не измерен. Проверка: сначала реализовать один путь целиком и прогнать те же последовательности; уменьшение числа владельцев состояния должно быть видно в code review и трассе.

**A-4. Переход на более мелкие аудиокадры уменьшит транспортную часть задержки.** Основание: Python сейчас ждёт полный 1-секундный блок, [sensing.py:308](../../implementation/ambient-awareness/butler_ambient/sensing.py:308). Уверенность High для устранения ожидания блока, Medium для общего пользовательского выигрыша: агент/TTS могут доминировать. Проверка: измерить по sample clock и не объявлять общий SLO достигнутым по одному этапу.
