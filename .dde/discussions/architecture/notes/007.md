# Нарисуй мне секундс-диаграмму для аудио-входа. Что происходит с разговором, то есть с фразой, когда она расшифровывается.

*Discussion: Architecture*

По текущему коду фраза **сначала собирается целиком, затем расшифровывается локально**. Проверка говорящего идёт параллельно; готовый текст передаётся в диалог без повторного распознавания.

```mermaid
sequenceDiagram
    actor U as Человек
    participant M as Микрофон
    participant L as Сбор реплики
    participant W as Whisper
    participant I as Проверка участников
    participant R as Обработка текста
    participant D as Диалог
    participant A as Агент

    U->>M: Произносит фразу
    Note over M,L: При включённом слушании
    loop Каждая секунда аудио
        M->>L: Аудиоблок
        M->>I: Проверка голоса этого блока
        L->>L: WebRTC VAD: есть ли речь?
    end

    Note over L: Сохранить начало перед речью<br/>Собирать до паузы от 0,45 с<br/>или ограничения в 20 с
    L->>W: Собранное аудио в памяти
    Note over W: Локальное распознавание<br/>без истории разговора
    W->>W: Проверить уверенность<br/>Отсеять выдуманные фразы на шуме
    W-->>R: Текст или пустой результат

    alt Текста нет
        R->>R: Записать диагностику и ждать речь
    else Текст получен
        R->>R: Показать услышанное<br/>Проверить эхо собственного голоса
        alt Собственное эхо
            R->>R: Не отвечать
        else Точный вопрос «Батлер, ты меня слышишь?»
            R-->>U: Готовое подтверждение
        else Обычная фраза
            I-->>R: Результаты проверки участников
            Note over R: Если проверка ещё идёт — дождаться её<br/>Устаревшую обработку отменить
            R->>R: Проверить занятость<br/>и допуск к личному разговору
            alt Ответ сейчас заблокирован
                R->>R: Оставить услышанное без ответа
            else Ответ допустим
                R->>D: Готовый текст + аудио + режим
                Note over D: Личный режим — доступный личный контекст<br/>Общий режим — короткая общая история
                opt Личная фраза выглядит незаконченной
                    D->>D: Подождать продолжения
                end
                D->>D: Проверить просьбу молчать<br/>Определить, кому сказано и что требуется
                Note over D: Smart Turn оценивает аудио в фоне<br/>Результат пока только в журнале
                alt Обращение не к Батлеру
                    D->>D: Молчать
                else Локальная команда или общий разговор
                    D-->>U: Локальная обработка и ответ
                else Личный запрос агенту
                    D->>A: Текст и разрешённый контекст
                    A-->>D: Результат
                    D-->>U: Озвучить ответ
                end
            end
        end
    end
```

Схема основана на [listening.py](/Users/boris/Projects/MacStudioButler/implementation/ambient-awareness/butler_ambient/listening.py:201), [transcriber.py](/Users/boris/Projects/MacStudioButler/implementation/ambient-awareness/butler_ambient/transcriber.py:159) и [conversation.py](/Users/boris/Projects/MacStudioButler/implementation/ambient-awareness/butler_ambient/conversation.py:1311). Пауза в 0,45 секунды — порог выделения реплики; из-за обработки секундными блоками она не означает ответ ровно через 0,45 секунды.
