## Question

Should the timeline group observations into sessions or show every observation?

## Why it matters

A busy hour produces about 600 observations, one per source per minute. A flat list is exact but long. Grouping consecutive minutes with the same activity into one session is easier to scan, but it hides per-minute detail until the session is opened.

## Options

- **A**: Flat list of observations, filtered by source
- **B**: Sessions (consecutive minutes with the same activity or call), expandable to the minute observations

## Recommended

B

## Answer

B. Sessions (consecutive minutes with the same activity or call), expandable to the minute observations
