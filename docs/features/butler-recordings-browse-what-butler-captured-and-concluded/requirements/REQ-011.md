## Requirement

Include the newer local Display and written conversation history work. Persist it across restarts, pause and elapsed days until explicit Clear, without automatic count pruning. Keep DEC-004/REQ-005 owner checks for Display history, selection and actions. An interrupted written turn must not restart automatically. Mail bodies and drafts remain in the mail store rather than being duplicated in UI history.

## Acceptance criteria

- [x] Real database reopen restores history, replacements and current selection.
- [x] Loss of owner verification hides retained Display history and refuses selection/actions.
- [x] Owner Clear removes the relevant history; access loss or restart does not delete it.
- [x] Interrupted turns are recorded as interrupted without automatic replay; mail bodies/drafts are not duplicated.
