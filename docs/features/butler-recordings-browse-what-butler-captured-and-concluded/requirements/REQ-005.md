## Statement

The system shall keep recordings, facts, transcripts and media local and visible only to the verified owner under the existing observation visibility rules; it shall not send them to the cloud agent. Generated images and Display history shall be visible only to the verified owner in both Recordings and Display.

## Acceptance Criteria

- [ ] Recordings, facts, transcripts and media are visible only to the verified owner under the existing observation visibility rules.
- [ ] Generated images and Display history are visible only to the verified owner in both Recordings and Display.
- [ ] Unverified users cannot view generated images or Display history in either Recordings or Display.
- [ ] The local voice navigation path sends no recording content or navigation request to the cloud agent.
- [ ] Capture and retention respect existing pause and participant-consent controls.
