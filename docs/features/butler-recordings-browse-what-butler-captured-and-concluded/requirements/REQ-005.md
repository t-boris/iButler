## Statement

The system shall keep recordings, facts, transcripts and media local and visible only to the verified owner under the existing observation visibility rules; it shall not send them to the cloud agent. Generated images and Display history inside Recordings remain owner-only. The local Display conversation, its cards/history and local controls are independent of biometric and observation checks (DEC-009).

## Acceptance Criteria

- [x] Recordings, facts, transcripts and media are visible only to the verified owner under the existing observation visibility rules.
- [x] Generated images and Display history inside Recordings are visible only to the verified owner.
- [x] The local Display remains visible, selectable and usable without owner verification or observation permission.
- [x] The local voice navigation path sends no recording content or navigation request to the cloud agent.
- [x] Capture and retention respect existing pause and participant-consent controls.
