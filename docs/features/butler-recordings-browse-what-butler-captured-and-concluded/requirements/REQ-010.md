## Requirement

Use the active core switch and window to describe future nightly research. A folder's active brief and historical run count do not prove nightly execution. Preserve actual receipt timestamps and results separately. Enable the requested future schedule and perform one tracked catch-up run for Sirius Art and MyDataCenter today, as authorized in Q-008.

## Acceptance criteria

- [x] Disabled or unavailable automation cannot advertise an enabled next run.
- [x] The next plan uses the active core window; last confirmed run/result remain independent.
- [x] Versioned configuration evidence shows only the Back Burner scenario switch changed.
- [x] Both catch-up runs have real terminal receipts and are described as daytime catch-up, not a past overnight run.
