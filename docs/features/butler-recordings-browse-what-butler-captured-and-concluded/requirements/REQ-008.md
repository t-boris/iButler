## Statement

The system shall let the owner open the Recordings section at a requested time using a local voice command.

## Acceptance Criteria

- [x] A local voice request naming a time opens the Recordings section at that time.
- [x] The command does not transmit the request or recording content to the cloud agent.

## Implementation evidence

Implemented in `butler_ambient/recordings.py`, `store.py`, capture/listening hooks and the native Recordings pane. Automated regressions: `implementation/ambient-awareness/tests/test_recordings.py`; full release results are recorded in ../implementation/verification.md.
