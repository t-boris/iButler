## Statement

The system shall let the owner preserve or delete individual media files from the timeline using existing controls, with deletion applying only to the selected file. Facts, transcripts, and other associated records remain subject to their own retention policies. The system shall also let the owner manually mark a current detected meeting for local retention of its microphone audio, system audio, and video originals for 30 days, subject to applicable capture and participant-consent gates, without automatically marking detected meetings.

## Acceptance Criteria

- [x] The owner can preserve an available individual media file from the timeline using the existing control.
- [x] The owner can delete an available individual media file from the timeline using the existing control.
- [x] Deleting a media file removes only the selected file.
- [x] Facts, transcripts, and other associated records remain subject to their own retention policies when a media file is preserved or deleted.
- [x] The owner can manually mark a current detected meeting for local retention of its audio and video originals.
- [x] A detected meeting is not automatically marked for retention.
- [x] For a manually marked meeting, microphone audio, system audio, and video originals are retained locally for 30 days, subject to applicable capture and participant-consent gates.

Implemented in `butler_ambient/recordings.py`, `store.py`, capture/listening hooks and the native Recordings pane. Automated regressions: `implementation/ambient-awareness/tests/test_recordings.py`; full release verification remains in progress.
