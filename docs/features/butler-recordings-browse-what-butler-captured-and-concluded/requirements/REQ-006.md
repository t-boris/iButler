## Statement

The system shall mark in the timeline the intervals when nothing was recorded or analysed (owner pause, service restart, buffer full, analysis missed or expired) with the reason.

## Acceptance Criteria

- [x] The pause of 2026-10-25 19:50–20:07 appears as a gap labelled «пауза»
- [x] A buffer-full interval appears as «буфер заполнен», a restart as «перезапуск», a missed or expired analysis as «не проанализировано»
- [x] Gap rows are not selectable as observations and offer no media

## Implementation evidence

Implemented in `butler_ambient/recordings.py`, `store.py`, capture/listening hooks and the native Recordings pane. Automated regressions: `implementation/ambient-awareness/tests/test_recordings.py`; full release verification remains in progress.
