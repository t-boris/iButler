## Statement

The system shall display or play available media associated with a timeline item, including key frames, generated images, preserved originals and originals still in the spool.

## Acceptance Criteria

- [x] Available key frames, generated images and image originals can be viewed.
- [x] Available audio and video originals can be played.
- [x] The interface indicates when an original is unavailable.
