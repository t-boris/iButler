## Finding

The full 0.11.1 ambient run failed the follow-up logging regression because its next result never appeared. The written turn published `answered` before finalizing the gateway-history marker. A result arriving in that gap could be marked as already accounted for. The isolated logging test passed, confirming the timing dependency rather than a deterministic permission failure.

## Resolution

Finalize the turn's history marker before publishing its terminal state. Keep the turn active while that bookkeeping runs, so a subsequent result cannot be swallowed by the completed turn's marker. Add a deterministic regression that holds marker finalization, verifies the answer is still active, then releases it and confirms the next result appears. All 10 follow-up regressions pass. Repeat the complete exact-source gate and CI before deployment.
