## Finding

PR #1 merged at main 171dabb after both CI jobs and exact-source verification passed. The normal release installer installed ambient 0.10.0/core 0.17.1, then stopped before restarting Butler because `configure_background` unconditionally read a missing `~/Library/LaunchAgents/sh.brew.ollama.plist`. This installation uses an independently managed background Ollama service.

## Resolution

Restarted the existing Butler launch agents and verified running 0.10.0/0.17.1, then restored the installer’s temporary configuration flags from its rollback backup. Repair `configure_background` to return an explicit unchanged/not-installed result when that optional plist is absent. Preserve existing plist validation and the already-configured service path. Add regressions for absent, existing and invalid launch-agent files. Do not create a Homebrew service or take over the manually managed process. Submit the repair through a follow-up PR from a fresh feat/butler-recordings branch at origin/main; never commit to main. Repeat the full release gate and deployment/version confirmation before finishing the goal.
