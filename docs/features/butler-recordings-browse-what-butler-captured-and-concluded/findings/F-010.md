## Finding

The available-media API handled originals awaiting analysis, but the day index was based on observations/events/transcripts/images. A previous day containing only pending originals could therefore be reached by an explicit date request but was missing from the picker. This matters when analysis is paused or delayed across midnight.

## Resolution

Include available raw/preserved media dates in the local day index, excluding logically expired meeting retention. Add an automated regression with a media-only day, no observations/events/transcripts, and verify both picker availability and playback-file access through the expanded session. Release the final patch as ambient 0.10.1. Repeat the exact-source release gate, CI, merge and normal deployment before closing the goal.
