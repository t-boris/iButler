## Finding

The owner's screenshot shows component titles truncated inside narrow fixed columns, clipped description text, and a red Knowledge row. Knowledge initializes as `configured`, but the component inventory reports ready only after a successful recall (`ready`). A configured, untried adapter is therefore falsely reported as unavailable.

## Resolution

Contain table labels inside clipping cells, wrap component names and selected help, and allow the component page to scroll vertically. Show configured Knowledge as “настроен” with “first search not yet performed”, separately from ready and failed states, without invoking recall. All 272 packaged native checks pass, including 1120/1280-width layout assertions; 13 settings regressions pass. Synthetic evidence: `evidence/followup/packaged-ui/butler-components-fixed.png`.
