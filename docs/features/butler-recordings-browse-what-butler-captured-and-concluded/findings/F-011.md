## Finding

The pending-original query checks legacy direct observation/media links. `observations.media_id` had no index, so a large backlog could scan every observation once for each pending file, blocking the service lock and potentially outlasting owner verification. A deterministic regression with 2,300 observations and 2,000 pending originals exceeded a five-million SQLite VM-instruction budget in that query before the fix.

## Resolution

Create an idempotent index on `observations(media_id)` for existing and new stores. The same full browser regression must complete within the VM budget; this avoids a flaky wall-clock performance threshold. Include the repair in ambient 0.10.1 and rerun the exact-source release gate and CI before deployment.
