## Finding

A synthetic day with 29,001 observations and 45,000 pending originals took 4.07 seconds to list after the database index repair. Each media file repeated canonical resolution of both storage directories, adding filesystem walks that can outlast the owner lease. The final access recheck correctly withholds expired content, but browsing can then appear unavailable.

## Resolution

Resolve the two containment roots once per browse request. Continue resolving and checking every media file individually, including symlink escapes; do not cache access or relax the final owner check. Extend the existing database-budget backlog regression to require exactly two root resolutions. Release as ambient 0.10.2 after exact-source verification and CI. Synthetic benchmark evidence is stored in `evidence/recordings/backlog-benchmark*.json`.
