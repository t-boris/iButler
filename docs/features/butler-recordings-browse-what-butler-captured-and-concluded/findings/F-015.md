## Finding

The first 0.11.0 paired local gate passed ambient verification but failed one of 403 core tests: the Back Burner card-validation integration constructed Display with only a config object. Persistent Display now requires a Store. CI explicitly skips this integration when its unversioned private vault library is absent, so the full installed-environment gate was necessary to find it.

## Resolution

Use a real Store under the test's existing temporary root and register its close cleanup. Keep all awkward-name/card validation assertions and the test's real-vault canaries. The focused card-validator test passes. Re-run the complete exact-source release gate with the existing face-model cache present, and require green CI before deployment. The failed first report and core log are retained under `evidence/followup/`.
