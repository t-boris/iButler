## Finding

After all GitHub Python/Node suites passed, the macOS release build failed in pre-existing audio code: runtime `if #available(macOS 27, *)` blocks still referenced symbols absent from the runner’s older SDK (`connectNode`, `installAudioTap`, `playAudio`, `withAUAudioUnit`). The local release uses Xcode 27.1 / Swift 6.4, where those symbols exist.

## Resolution

Wrap those SDK-27-only branches in Swift 6.4 compiler guards and keep the existing older audio API path for older compiler/SDK builds. The local macOS 27 runtime path and spoken behavior are unchanged. Verify with the local native build/AEC smoke and the actual GitHub runner’s older SDK build. This is a build compatibility repair required by the release gate, not new spoken-response work.
