## Finding

The initial GitHub macOS run reached the full core suite but 190 tests failed because they source-copy unversioned private installed tools (vault, inbox, mail, news/video, Todoist, YouTube and the separate Tetyana workspace). The same 402 tests passed locally with the actual workspace installed. The repository README already identifies private workspace tests as environment-dependent, and some other integration suites already skip absent dependencies.

## Resolution

Add exact-file preconditions to the affected integration fixtures. On clean checkouts they explicitly report missing private dependencies as skips; they continue to run normally in full local release verification. Keep public-checkout unit tests, all new Recordings regressions, native UI checks and release builds in GitHub CI. Do not publish private installed source as test fixtures. Subsequent full local and GitHub results are recorded in implementation/verification.md.
