## Finding

The new Recordings pane and Display cleared private cached content on a failed state poll, but the older observation-history detail and gallery metadata could remain during the existing short connection grace period. Gallery selection could restore a cached image from those retained paths.

## Resolution

Clear stored observation rows/detail and gallery records, paths, labels and reveal controls on the first failed state poll. Keep the existing grace period for non-private health/status text. Add a native regression proving all stored-content caches are empty on that first failure. Repeat exact-source release verification for the changed native panel before deployment.
